# Blockchain Notes ⛓️

## What is a Blockchain?

A blockchain is a distributed data structure where transactions are
grouped into blocks and linked using cryptographic hashes.

## Core Concepts

### Block

A block generally contains:

- Block number
- Timestamp
- Transactions
- Previous block hash
- Current block hash
- Additional metadata

### Hash

A cryptographic hash converts input data into a fixed-length output.

Changing even a small part of the input should produce a completely
different hash.

### Transaction

A transaction represents an operation recorded by the network.

Examples:

- Transfer of assets
- Contract interaction
- State update

### Consensus

Consensus allows independent nodes in a distributed network to agree
on the state of the blockchain.

Common approaches include:

- Proof of Work
- Proof of Stake
- Byzantine Fault Tolerant protocols

### Distributed Network

Instead of relying on a single central server, multiple nodes maintain
and communicate about the state of the network.
